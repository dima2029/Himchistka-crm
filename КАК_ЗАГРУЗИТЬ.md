# Как загрузить файлы в GitHub репозиторий

## Вариант 1 — Через браузер (проще)

1. Зайди на https://github.com/dima2029/Himchistka-crm
2. Нажми **Add file → Upload files**
3. Загрузи ВСЕ файлы из этой папки:
   - index.html
   - render.yaml
   - README.md
4. Нажми **Commit changes**

## Вариант 2 — Через командную строку

```bash
git clone git@github.com:dima2029/Himchistka-crm.git
cd Himchistka-crm
# Скопируй все файлы сюда
git add .
git commit -m "Add CRM files"
git push
```

## После загрузки — настрой Render

1. Зайди на https://dashboard.render.com
2. Найди свой сервис himchistka-crm
3. Нажми **Manual Deploy → Deploy latest commit**
4. Подожди 1-2 минуты
5. Сайт заработает на https://himchistka-crm.onrender.com
