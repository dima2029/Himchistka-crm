# Химчистка CRM

База клиентов химчистки. Открывается в браузере без установки.

## Пароль входа
`1234`

## Возможности
- Поиск по телефону и адресу
- История заказов клиента
- Статистика и графики
- Напоминания (1-2-3+ года)
- Добавление и редактирование заказов
- Импорт/экспорт Excel
- Печать чека
- Светлая/тёмная тема
